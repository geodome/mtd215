# Setup for VSCode on MacOS 

## Install VSCode

* Downlood and install Visual Studio Code at https://code.visualstudio.com/download
* Install the C/C++ extension by Microsoft

## Install Homebrew

* Download and install Homebrew at https://brew.sh/

## Install SDL2
* We will be installing the following packages:
    * the main SDL2 library
    * the SDL2 image extension for handling imqge files
    * the SDL2 ttf extension to handle true type fonts for text rendering
    * the SDL2 mixer extension to handle sound
    * the SDL2 network extension to handle networking
* Inside terminal, run the following commands:
    * `brew install SDL2`
    * `brew install SDL2_image`
    * `brew install SDL2_ttf`
    * `brew install SDL2_mixer`
    * `brew install SDL2_net`

## Setup C/C++ Project with SDL2
* This setup assumes the following project directory structure
    * `mtd215_tma/`    
        `├── question1.cpp`  
        `├── question2.cpp`  
        `├── question3.cpp`  
        `└── question4.cpp` 

* Each `.cpp` file represents an isolated self-contained program, ie. each `.cpp` file contains a `main()` function and all the necessary building blocks for it to function witin the same file..
* This setup is useful for answering the TMA.
### C/C++ Configurations (UI)
* Type shift+cmd+p
* Select C/C++ Configuration (UI)
* Choose `Mac` for Configuration name
* For Compiler, choose `/usr/bin/g++`
* Add the following lines to Compiler arguments
    * -L/opt/homebrew/lib
    * -lSDL2
    * -lSDL2_image
    * -lSDL2_ttf
    * -lSDL2_mixer
    * -lSDL2_net
* for Intellisense Mode
    * choose `macos-gcc-arm64` if you are on Apple Silicon
    * choose `macos-gcc-x64` if you are on Intel CPU
* Append `/opt/homebrew/include` to Include Path
    * this enables intellisense to find the SDL2 header files and provides code hinting and autocomplete
* Choose `C++ 23` for C++ Standard

### Task Runner
Then vscode will generate the following `.vscode/tasks.json`
```json
{
    "tasks": [
        {
            "type": "cppbuild",
            "label": "C/C++: g++ build active file",
            "command": "/usr/bin/g++",
            "args": [
                "-fdiagnostics-color=always",
                "-g",
                "${file}",
                "-o",
                "${fileDirname}/${fileBasenameNoExtension}",
                "-I/opt/homebrew/include",
                "-L/opt/homebrew/lib",
                "-lSDL2",
                "-lSDL2_image",
                "-lSDL2_ttf",
                "-lSDL2_mixer",
                "-lSDL2_net"
            ],
            "options": {
                "cwd": "${fileDirname}"
            },
            "problemMatcher": [
                "$gcc"
            ],
            "group": {
                "kind": "build",
                "isDefault": true
            },
            "detail": "Task generated by Debugger."
        }
    ],
    "version": "2.0.0"
} 
```

### Testing

* Compile and run `main.cpp`
* A blank window should pop up and the program terminates when u closed the window.
