# Setup VSCode for MacOS

## Working with the C++ compiler

* The .vscode/tasks.json informs VSCode how to compile the cpp file.
* Below is the .vscode/tasks.json which we will use for our C++ project.

```json
{
    "tasks": [
        {
            "type": "cppbuild",
            "label": "C/C++: g++ build with SDL2",
            "command": "/usr/bin/g++",
            "args": [
                "-fdiagnostics-color=always",
                "-std=c++23",
                "-g",
                "${file}",
                "-o",
                "${fileDirname}/${fileBasenameNoExtension}",
                "-I/opt/homebrew/include",
                "-L/opt/homebrew/lib",
                "-lSDL2",
                "-lSDL2_image",
                "-lSDL2_ttf",
                "-lSDL2_mixer"
            ],
            "options": {
                "cwd": "${fileDirname}"
            },
            "problemMatcher": [
                "$gcc"
            ],
            "group": {
                "kind": "build",
                "isDefault": true
            },
            "detail": "Task generated by Debugger."
        },
  
    ],
    "version": "2.0.0"
}
```
* `"command": "/usr/bin/g++"` tells VSCode to use the g++ compiler stored at this address
* `args` contains the list of arguments for the g++ compiler
