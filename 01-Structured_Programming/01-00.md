## Native Data Types
* integers
    * `int`
        * on 32-bit and 64-bit Windows, `int` is a signed 32-bit integer
        * on 32-bit Linux and UNIX, `int` is a signed 32-bit integer 
        * on 64-bit Linux and UNIX, `int` is a signed 64-bit integer
        * MacOS belongs to the UNIX family
    * `uint8_t`: 8-bit unsigned integer, used by SDL2 Library to represent colour
* floating point number
    * `float`: 16-bit floating point representation
    * `double`: 32-bit floating point representation
* character
    * `char`: 8-bit encoding of ASCII characters
* boolean
    * `bool`: `true` (1) or `false` (0)
* How to declare
     ```C++
     int a1;                // uninitialised integer a1.
     int a2 = 3;            // integer a2 with initial value of 3
     int a3{10};            // integer a3 with initial value of 10, using initialiser syntax
     int a4{};              // initialise integer a4 with default value of 0

     double b;              // uninitialisd double
     double pi = 3.14159;   // double pi with initial value of 3.14159
     double euler{2.71828}; //  initialise double euler with 2.71828

     char c1;               // uninitialised character
     char c2 = 'a';         // character c2 initialised with 'a' value
     char c3{'d'};          // character d3 initialised with 'd'
     char c4{};             // char c4 initialised with default value '\0'
     
    bool e;                 // uninitialised boolean variable
    bool e1 = true;         // You may initialise a boolean variable with true/false
    bool e2 = 0;            // alterantive representation of true/false is 1/0
    bool e3{}               // default initialisation value is false
    ```

* The value of an uninitialised native data type variable is non-deterministic.

* These data types are native to the CPU. ie. the CPU has built-in instructions that understand these data types.

## Arrays
* An array stores all its elements in a contiguous block of adjacent memory addresses

## `std::string` and `c-style string`

* `c-style string` is a special case of character array
    * a character array that ends with `\0` character 
    * "hello" = {'h', 'e', 'l', 'l', 'o', '\0'}
